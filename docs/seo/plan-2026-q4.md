## 3. Сквозное

1. **Индексация в Яндексе — пробел.** API Вебмастера 13.10 недоступен, Метрика показывает 2 визита из Яндекса за месяц. Нужно: повторить API (`summary.sh`, `insearch.sh`, `indexing.sh --action samples`, `search_events.sh`), при неудаче — владелец выгружает вручную «Страницы в поиске» и «Исключённые». Эффект В (Яндекс — основной поиск для ниши в РФ), 0,25 дня.
2. **Sitemap и сигналы свежести.** Сейчас у 45 записей `lastModified: now`: каждый день «меняются» все страницы, и поисковики перестают верить lastmod. Нужно: реальные даты (mtime статей, дата контента, для ежедневных — сегодня); sitemap-index по разделам, чтобы в GSC/Вебмастере видеть охват по разделу; ссылки на /lunnyy-kalendar/2026-10-01…05 вне sitemap — убрать или включить. IndexNow уже есть в доске (`board/yandex.py`) — проверить, что после деплоя уходит пачка изменённых URL. Эффект В, 1 день.
3. **Перелинковка и хабы.** Главная проблема — Таро (карты не найдены Google) и лунные дни. Правило: каждая страница шаблона — не дальше 2 кликов от хаба, хаб — 1 клик от главной; блок «Смотрите также» с анкорами-запросами. Делается внутри карточек разделов.
4. **Микроразметка.** Есть Article, BreadcrumbList, FAQPage, ItemList, Person, WebApplication, Organization с логотипом (8564cc80). Добавить `sameAs` (Telegram, ВК, Дзен) в Organization и `author` → Person со ссылкой на `/avtory/<slug>` во всех Article. Эффект С.
5. **E-E-A-T.** Нет страницы «О проекте» с редакционной политикой (как считаем — есть `/astrologiya/kak-my-schitaem`, но она не в подвале), контактов и ссылок на соцсети; страница автора неизвестна Google. Важно: биография автора на сайте должна быть правдивой — проверить с владельцем. Эффект С, 1 день.
