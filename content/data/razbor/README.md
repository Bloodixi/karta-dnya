# Банк текстов платного разбора по дате рождения

Тексты собираются `src/lib/razbor.ts` в персональный документ. Абзацы внутри строки — через `\n\n`. Обращение на «ты».
Тон: спокойный, тёплый, конкретный; без запугивания, без медицинских и финансовых обещаний, без упоминаний ИИ.
Это платный продукт: тексты глубже и конкретнее, чем бесплатные страницы сайта (`content/data/numerology*.json`) — не копировать их.
Проверка: `node scripts/razbor-check.mjs`.

## Версии
Версия банка (`RAZBOR_VERSION` в `src/lib/razbor.ts`) записывается в ссылку и metadata платежа: купленный разбор показывается теми текстами, с которыми его купили.
Перед правкой, которая меняет выдачу (тексты, новые ключи): скопировать текущие `*.json` в `razbor/v<текущий номер>/`, потом увеличить `RAZBOR_VERSION` и править файлы в корне.
Старые ссылки без версии — версия 1.
Версия 2 (16.10.2026): разделы «Сведение» и «Памятка на год», «Как посчитано» в «Твоих числах», 81 текст месяцев, число судьбы в следующем году. Сборка по версии — `v2` в `buildRazbor`; банк версии 1 — `razbor/v1/`.
Версия 3 (16.10.2026): возраст — раздел «Твой период жизни» (пики), абзацы по возрастной группе к году, любви и работе; примеры в текстах месяцев, «судьба × год» и годов переписаны под любой возраст. Банк версии 2 — `razbor/v2/`.
