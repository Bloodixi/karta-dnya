# Банк текстов платного разбора по дате рождения

Тексты собираются `src/lib/razbor.ts` в персональный документ. Абзацы внутри строки — через `\n\n`. Обращение на «ты».
Тон: спокойный, тёплый, конкретный; без запугивания, без медицинских и финансовых обещаний, без упоминаний ИИ.
Это платный продукт: тексты глубже и конкретнее, чем бесплатные страницы сайта (`content/data/numerology*.json`) — не копировать их.
Проверка: `node scripts/razbor-check.mjs`.

| Файл | Ключи | Поля (длина в знаках) |
|---|---|---|
| `destiny.json` | "1"…"9","11","22","33" | `title` (2–4 слова, образ числа), `essence` 1400–2000, `strengths` 800–1200, `shadows` 800–1200, `calling` 800–1200 |
| `destiny-life.json` | те же 12 | `love` 900–1300, `work` 900–1300, `advice` — массив из 5 советов по 120–250, `easy` — числа 1–9, с кем легко, `hard` — с кем трудно, `pairNote` 300–600 |
| `birthday.json` | "1"…"31" | строка 500–900 — таланты, которые даёт день рождения |
| `pythagoras.json` | "1"…"9" | `title`, `intro` 250–450 (что значит ячейка), `levels` — 4 строки 350–650: пусто, одна цифра, две, три и больше |
| `year.json` | "1"…"9" | `title` (2–4 слова), `theme` 800–1200, `first` 450–750 (первое полугодие), `second` 450–750, `advice` 300–500 |
| `month.json` | "1"…"9" | строка 280–480 — характер личного месяца |
